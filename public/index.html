Organizador de estudos

No Meu Ritmo!

Um projeto simples para organizar matérias, montar um plano de estudos do dia e registrar sessões com tempo, foco e observações. Foi feito em Flask, Flet e Tailwind para uma atividade universitária.

Abrir Swagger Ver API

Como a aplicação funciona

1. Consulte o plano do dia

A API retorna blocos de estudo com matéria, horário, duração e meta.

2. Abra o app em Flet

O frontend local consome os endpoints Flask e mostra os dados em uma tela simples.

3. Registre uma sessão

O formulário envia os dados para o endpoint POST com validação Pydantic.

Tecnologias

Flask, Blueprints, Pydantic, Flasgger, Flet, HTML e Tailwind CSS.

Dados

Os dados ficam em memória, como permitido na proposta da atividade.

Execução

Rode python app.py para a API e python frontend/main.py para o Flet.
